PREGUNTAS

  • ¿Cuál es la diferencia entre padding y margin?

    El margin es el espacio exterior que separa un elemento de otros, mientras que el padding es el espacio interior entre el contenido y su propio borde.


  • ¿Por qué se recomienda usar box-sizing: border-box?

    Porque incluye el padding y el grosor del borde dentro del tamaño total de la caja, evitando que los elementos se "ensanchen" más de lo que definiste.


  • ¿Qué significa diseñar con enfoque mobile-first?

    Es una estrategia donde se escribe el CSS pensando primero en celulares y pantallas pequeñas, añadiendo complejidad para laptops mediante media queries después.


  • ¿En qué situaciones preferirías rem sobre px?

    Casi siempre para textos y espaciados, ya que los rem son relativos y permiten que la página sea accesible si el usuario cambia el tamaño de fuente en su navegador.
