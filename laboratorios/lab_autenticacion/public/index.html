¿Qué otras formas de autenticación existen?

Este lab usa sesiones + usuario/contraseña con bcrypt.

  • JWT: Token firmado que el cliente guarda y manda en cada petición, sin sesión en el servidor.
  • Login Social: Autenticarse con Google, GitHub, etc. sin crear cuenta nueva.
  • 2FA / MFA: Contraseña + segundo factor (SMS, Google Authenticator, llave física).
  • Biométrica (WebAuthn): Huella o Face ID desde el navegador con la API FIDO2.
