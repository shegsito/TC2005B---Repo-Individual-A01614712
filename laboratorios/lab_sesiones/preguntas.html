Laboratorio OWASP Top 10

  • ¿En qué consiste el ataque "A01: Control de Acceso Defectuoso" (Broken Access Control)?

    Este problema ocurre cuando la aplicación web no verifica correctamente si un usuario tiene permiso para ver ciertos datos o realizar una acción.

    Ejemplo: Un usuario cambia el número en la barra de direcciones de su navegador (de perfil?id=101 a perfil?id=102) y el sistema le muestra la información privada de otra persona sin validar si tiene permiso.

  • ¿Cómo se puede prevenir este ataque?

    Para evitar este riesgo se deben aplicar las siguientes medidas:

    • Revisar permisos en el servidor.
    • Bloquear todo por defecto.
    • Usar identificadores difíciles de adivinar
