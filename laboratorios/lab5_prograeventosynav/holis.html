¿Por que es una buena practica usar JavaScript para checar que sean validos los inputs de las formas antes de enviar los datos al servidor?

Por que de esta forma tenemos un seguimiento más formal que en el futuro nos evitara caer en muchos bugs, tal vez estamos enviando datos incorrectos al server y no nos damos cuenta hasta que todo sale mal.

¿Como puedes saltarte la seguridad de validaciones hechas con JavaScript?

Se puede abrir las DEVTools y modificar atributos como requires o modificando el JS desde ahí mismo antes de correr

Si te puedes saltar la seguridad de las validaciones de JavaScript, entonces ¿por que la primera pregunta dice que es una buena practica?

Porque al validar buscamos crear un entorno más comodo, el servidor tiene que validar todo y asumir que el cliente tiene intenciones raras.
