Preguntas

  1. ¿Cuál es la diferencia entre Internet y la World Wide Web?

    2. El internet es la estructura física y lógica que conecta computadoras, mientras que la WWW es un servicio que funciona sobre internet, es el sistema de documentos de hipertexto

  2. ¿Cuáles son las partes de un URL?

    3. Las partes de una URL son las siguientes:

      Protocolo: https://

      Subdominio: www

      Puerto: 80

      Ruta: /route/path

      Parámetros o query: ?id=10

      Fragmento: #seccion

  3. ¿Cuál es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH, DELETE?

      4. GET: solicita datos de un recurso en lectura

      HEAD: solicita solo los encabezados

      POST: Envía datos para crear un nuevo recurso

      PUT: Reemplaza por completo un recurso existente

      PATCH: Aplica modificaciones a un recurso

      DELETE: ELimina un recurso específico

  4. ¿Qué método HTTP se debe utilizar al enviar un formulario HTML, por ejemplo cuando ingresas tu usuario y contraseña en algún sitio? ¿Por qué?

    5. Para esa acción se utiliza POST, porque se están enviando datos al HTTP, no esta en la URL

  5. ¿Qué método HTTP se utiliza cuando a través de un navegador web se accede a una página a través de un URL?

    6. Se utiliza el GET, esto para pedir al server que entreguen la dirección

  6. ¿Si un servidor web devuelve una respuesta HTTP con código 200. ¿Qué significa esto? ¿Ocurrió algún error?

    7. Significa que esta bien "OK". La solicitud solo fue exitosa.
